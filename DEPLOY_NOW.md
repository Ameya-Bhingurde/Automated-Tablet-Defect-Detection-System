# 🚀 QUICK DEPLOYMENT STEPS

## Deploy Your App in 5 Minutes! ⏱️

### **Step 1️⃣: Go to Render**
🔗 **URL**: https://render.com

### **Step 2️⃣: Sign Up/Login**
- Click "Get Started" (top right)
- Sign in with GitHub for easy integration

### **Step 3️⃣: Create New Web Service**
1. Click **"New +"** button (top right)
2. Select **"Web Service"**
3. Connect your GitHub account (if first time)
4. Find and select: **"Ameya-Bhingurde/Automated-Tablet-Defect-Detection-System"**
5. Click **"Connect"**

### **Step 4️⃣: Configure Settings**

Copy and paste these exact values:

```
Name: tablet-defect-detection
Region: [Choose closest to you]
Branch: main
Root Directory: [Leave blank]
Runtime: Python 3
Build Command: pip install -r requirements.txt
Start Command: streamlit run app.py --server.port=10000 --server.address=0.0.0.0
Instance Type: Free
```

### **Step 5️⃣: Deploy!**
1. Click **"Create Web Service"** (bottom)
2. Wait ~8-12 minutes for:
   - ⏳ Installing dependencies (5-10 min)
   - 🤖 Training model automatically (2-3 min)
   - 🚀 Starting app (30 sec)

### **Step 6️⃣: Access Your App!**
Your app will be live at:
```
https://tablet-defect-detection-xxxx.onrender.com
```
